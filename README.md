## 🎯 Project Overview

This project presents an interactive **India vs England T20 World Cup 2026 Cricket Dashboard** built using Microsoft Excel.

The dashboard transforms cricket match data into meaningful visual insights covering batting, bowling, boundaries, wickets, partnerships, and overall team performance.

---

## 📌 Dashboard Features

- 🏏 Total Runs
- 🎯 Total Wickets
- 💥 Total Fours
- 🚀 Total Sixes
- ➕ Extras
- ⭐ Highest Individual Score
- 📈 Score Progression
- 📊 Runs Per Over
- 🔥 Boundary Comparison
- 🎳 Wicket Distribution
- 🏆 Top Run Scorers
- 🎯 Top Wicket Takers
- 🤝 Partnership Analysis
- 📝 Match Summary
- 👤 Player Performance
- India vs  England Comparison

---

## 🎛️ Interactive Filters

The dashboard includes interactive slicers for:

- Innings
- Over
- Batter / Striker
- Bowler
- Batting Team

These slicers allow users to dynamically explore different parts of the match.
